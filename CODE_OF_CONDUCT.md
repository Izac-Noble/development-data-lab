# Code of Conduct

Development Data Lab follows the Contributor Covenant Code of Conduct.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while addressing problems directly.
- Keep discussions focused on improving the project.
- Welcome learners and first-time contributors.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks or sustained disruption.
- Publishing private information without permission.

## Reporting

Report concerns to the repository maintainer. Reports should include enough context to understand the issue and respond fairly.
